SealoryNFT — установка

1. Загрузите index.js, prices.js и package.json в корень проекта.
2. Установите Node.js 20+ и выполните npm install.
3. Укажите переменную окружения BOT_TOKEN (токен из BotFather).
4. Выполните npm start.
5. Администратор Telegram ID: 8882210622. Для получения уведомлений администратор должен открыть бота и нажать /start.
6. Контакт поддержки и аккаунт получения подарков: @Sealory.
7. Канал: @SealoryBio.
8. Данные хранятся в sealory-data.json; для сохранности настройте постоянное хранилище на хостинге.

ВНИМАНИЕ: проверка поступления NFT выполняется администратором, не автоматически. После подтверждения получения NFT пользователь подтверждает заявку на выплату в профиле. Администратор отдельно отмечает выплату как выполненную.

В текущем варианте реквизиты карты не сохраняются целиком: только последние 4 цифры и название банка. Для реальных выплат потребуется безопасный способ получения реквизитов.
